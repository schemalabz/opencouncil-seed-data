# OpenCouncil Seed Data

Seed data for bootstrapping OpenCouncil development and testing environments with realistic data.

## Files

### `seed_data.json`

Complete application state for a set of cities and council meetings, including all related entities. Used to populate the database during development seeding.

**Contains:** Cities, meetings, administrative bodies, parties, persons, topics, speaker segments, highlights, and podcast specs. See `metadata.pairs` inside the file for the specific city/meeting combinations included.

**Schema:** Top-level keys are `metadata`, `topics`, `cities`, `administrativeBodies`, `parties`, `persons`, `meetings`. See `metadata.schema_version` for the current version.

**Generated by:** The seeding export script in the main [OpenCouncil](https://github.com/schemalabz/opencouncil) repository. See the [Database Seeding documentation](https://github.com/schemalabz/opencouncil/blob/main/docs/database-seeding.md) for details.

**To regenerate:** Run the seed export from the main repository against a populated database.

**Consumed by:** The main OpenCouncil app's database seeding process, which imports this file to populate a fresh development database.

### `diavgeia_municipalities.json`

Directory of all Greek municipalities on [Diavgeia](https://diavgeia.gov.gr) (Government Transparency Portal), with their organizational units profiled by decision count.

**Contains per municipality:**
- `uid` — Diavgeia organization identifier
- `label` — Greek name (e.g., `ΔΗΜΟΣ ΖΩΓΡΑΦΟΥ`)
- `latinName` — ASCII name used in API URLs
- `dateRange` — Period over which decision counts were sampled
- `units` — All organizational units with:
  - `uid`, `label` — Unit identifier and name
  - `count` — Number of decisions published in the sample period
  - `patternMatch` — Whether the unit name matches council-relevant patterns (council, committee, mayor)

**Generated by:** The `diavgeia-lookup` script in [opencouncil-tasks](https://github.com/schemalabz/opencouncil-tasks):

```bash
npx tsx scripts/diavgeia-lookup.ts all --profile=exclude-empty --json > diavgeia_municipalities.json
```

This fetches all organizations from the Diavgeia API, filters to municipalities, then queries decision counts for every active unit in each one.

**To regenerate:** Run the command above from the opencouncil-tasks repository. The `--profile=exclude-empty` flag drops units with zero decisions in the sample period. Omit it to include all units.

**Consumed by:** The main OpenCouncil app uses this to:
- Look up Diavgeia organization UIDs when onboarding a new city
- Identify which organizational units publish council-relevant decisions (those with `patternMatch: true`)
- Provide a municipality directory for city selection

## Contributing

When contributing new seed data:
1. Generate the data using the appropriate script (see above)
2. Ensure the data follows the established structure
3. Update this README if the scope changes
4. Submit a pull request with the new data file
